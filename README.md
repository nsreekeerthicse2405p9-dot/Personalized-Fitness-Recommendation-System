# 🧘 Personalized Fitness Recommendation System

## 📌 Project Overview
A smart fitness system that provides personalized **Yoga, Physiotherapy exercises, fitness tips, and posture analysis** based on user needs.

## 🎯 Objectives
- Provide personalized fitness recommendations.
- Analyze body posture.
- Suggest suitable Yoga and Physiotherapy exercises.

## ✨ Features
- 🧘 Yoga recommendations
- 🏃 Physiotherapy exercises
- 📊 BMI analysis
- 🧍 Posture analysis
- 💡 Fitness tips

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend and ML |
| Streamlit | User Interface |
| OpenCV | Image Processing |
| MediaPipe | Posture Analysis |
| Pandas | Data Processing |
