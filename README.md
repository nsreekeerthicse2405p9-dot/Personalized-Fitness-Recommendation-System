## 📌 Project Overview

A smart fitness system that provides personalized **Yoga, Physiotherapy exercises, fitness tips, and posture analysis** based on user needs.

## 🎯 Objectives

- Provide personalized fitness recommendations.
- Analyze body posture.
- Suggest suitable Yoga and Physiotherapy exercises.
- Help users follow a healthy fitness routine.

## ✨ Features

- 🧘 Yoga recommendations
- 🏃 Physiotherapy exercises
- 📊 BMI analysis
- 🧍 Posture analysis
- 💡 Fitness tips

## ⚙️ Installation

1. Install Python.
2. Download or clone the project from GitHub.
3. Open the project folder in Command Prompt.
4. Install the required libraries:

```bash
pip install streamlit pandas numpy opencv-python mediapipe
```

5. Run the application:

```bash
streamlit run app.py
```
